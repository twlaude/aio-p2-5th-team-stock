# 설계 문서 읽는 순서

팀원이 개발을 시작할 때는 아래 순서로 읽는다.

1. 루트 `README.md`
2. 루트 `실행_폴더_구분.md`
3. `shared/CONNECTION_CONTRACT.md`
4. 자신이 담당한 서비스의 `GUIDE.md`
5. `shared/contracts/`의 담당 계약
6. `gide/06_CONFIRMED_LOCAL_STRUCTURE.md`
7. `gide/07_AGENT_WORKFLOW_GUIDE.md`

`gide/00`부터 `gide/05`까지는 아이디어와 구조를 잡는 과정에서 작성한 초기 문서다. 최신 문서 및 `shared` 계약과 충돌하면 루트 문서, `shared` 계약, `gide/06`, `gide/07` 순으로 우선한다.
