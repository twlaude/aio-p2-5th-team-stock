# Disclosure Clients

외부 시스템과의 통신만 담당한다. MCP Tool의 판단, 문서 정제, RAG 검색 정책은 이 계층에 두지 않는다.

## 구성 예정

- `dart_client.py`: OpenDART 인증키를 사용해 기업 고유번호 목록, 공시 목록, 공시 원문을 조회한다.
- `repository.py`: PostgreSQL·pgvector에 기업 매핑, 문서 메타데이터, 원문, 청크와 임베딩을 저장·조회한다.
- `embedding_client.py`: 설정된 임베딩 제공자와 모델로 텍스트를 벡터화한다.

## OpenDART 사용 원칙

- 인증키는 `DART_API_KEY` 환경변수에서만 읽는다. 코드, 로그, 예외 메시지와 응답에 포함하지 않는다.
- 기업 고유번호 목록은 주기적으로 동기화해 회사명·종목코드에서 `corp_code`를 찾는 데 사용한다.
- 공시 목록으로 사업보고서의 접수번호를 찾은 뒤, `rcept_no`로 원문 파일을 받는다.
- 원문 파일은 접수번호를 키로 저장한다. 동일 접수번호는 다시 받지 않는다.
- HTTP 시간 초과, 재시도, 요청 제한 오류는 외부 API 오류로 구분해 상위 계층에 전달한다.

## 캐시 전략

모든 기업의 보고서를 사전 수집하지 않는다. 사용자가 요청한 기업의 최신 사업보고서만 필요 시 수집하고, 이미 색인된 최신 접수번호는 재사용한다. 새 접수번호가 발견될 때만 원문·청크·임베딩을 갱신한다.
