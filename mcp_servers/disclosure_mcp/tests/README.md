# Disclosure MCP Tests

외부 API에 의존하지 않는 단위 테스트를 기본으로 하고, 별도 표시한 통합 테스트에서만 OpenDART·DB·임베딩을 사용한다.

## 단위 테스트

- 기업명·종목코드에서 올바른 `corp_code`를 찾는지
- 동명이인, 미등록 기업, 종목코드 불일치를 안전하게 처리하는지
- 최근 공시의 기간·정렬·제한값과 접수번호·URL 보존 여부
- 사업보고서 접수번호로 원문·메타데이터를 연결하는지
- 미색인 문서 수집, 기존 문서 캐시 재사용, 새 접수번호 갱신 여부
- 기업·문서 종류 선필터 후 관련 청크만 반환하는지
- 결과 없음, DART 요청 제한, 네트워크 오류, 설정 오류를 구분하는지

## Mock 데이터

삼성전자 공시 2~3건과 사업보고서 청크를 고정 fixture로 둔다. 테스트에는 실제 API 키·실제 개인 환경변수를 사용하지 않는다.

## 계약 테스트

세 Tool의 입력·출력이 `shared/contracts/disclosure/README.md`의 필드와 제한값(`top_k` 최대 5)을 준수하는지 검증한다.
