16:9 비율, 1920×1080 해상도의 한국어 데스크톱 웹 UI 시안을 만들어줘.

서비스 이름은 “살래? 말래?”이며, 사용자가 궁금한 국내 주식 종목을 검색하면 시장 반응과 확인된 근거를 쉽게 설명하는 서비스야.

이번에는 종목 분석 요약 화면에서 “왜 이렇게 판단했나요?” 버튼을 누른 뒤 표시되는 상세 근거 화면 한 장만 만들어줘.

이 요청에 이전에 만든 FE2 종목 분석 요약 화면 이미지가 첨부되어 있다면, 그 이미지의 헤더, 색상, 카드 모양, 마스코트 스타일을 동일하게 유지해줘. 참고 이미지가 없더라도 아래 디자인 조건으로 완성해줘.

디자인 조건:

- 스마트폰 화면이 아닌 정면 데스크톱 웹 화면
- 한국의 현대적인 핀테크 서비스처럼 깔끔하고 친근한 분위기
- 특정 증권사나 기존 서비스의 로고·캐릭터를 복제하지 않은 독창적인 디자인
- 밝은 아이보리 배경
- 짙은 네이비 텍스트
- 코랄 레드와 차분한 블루를 강조색으로 사용
- 둥근 카드, 부드러운 그림자, 넉넉한 여백
- 초보자와 중장년층도 이해할 수 있는 큰 글자
- 화면 오른쪽 위에 작은 “DEMO” 배지 표시
- 전문 보고서처럼 너무 딱딱하지 않으면서 근거를 투명하게 확인할 수 있는 화면

상단:

- 왼쪽 서비스명: “살래? 말래?”
- 페이지 제목: “삼성전자 분석 근거”
- 작은 문구: “Mock 데이터 · 실제 투자 정보가 아닙니다”
- 분석 기준 시각 영역
- 오른쪽에 “요약으로 돌아가기” 버튼

화면 왼쪽 약 65% 영역:

세 개의 세부 근거 섹션을 카드 또는 탭 형태로 구성해줘.

첫 번째 섹션: “커뮤니티 반응”

- 감성 비율을 보여주는 간단한 막대그래프
- “긍정 74%”
- “중립 16%”
- “부정 10%”
- 주요 기대 태그: “HBM”, “10만전자”, “업황 회복”
- 주요 우려 태그: “파운드리 적자”, “외국인 매도”
- 작은 문구: “커뮤니티 의견은 확인된 사실이 아닙니다.”

두 번째 섹션: “최신 뉴스”

- 기사 카드 3개
- 각 기사 카드에 제목이 들어갈 영역
- 언론사 영역
- 발행 시각 영역
- “출처 확인” 버튼
- 주요 주제 태그: “HBM”, “반도체”, “실적”
- 작은 문구: “비슷한 내용의 기사 8건을 하나의 이슈로 묶었습니다.”

세 번째 섹션: “기업보고서·공시”

- 공식 자료 카드 3개
- “사업 방향”
- “재무·실적”
- “위험 요소”
- 각 카드에 공시 날짜 영역과 “원문 보기” 버튼
- 작은 문구: “오늘 확인된 신규 대형 계약 공시는 없습니다.”

화면 오른쪽 약 35% 영역:

AI 종합 설명 카드:

- FE2 요약 화면과 동일한 AI 마스코트
- 제목: “확인된 사실”
- 제목: “시장 반응”
- 제목: “서로 다른 부분”
- 제목: “추가로 확인할 내용”
- 각 제목 아래에 짧은 설명이 들어갈 2~3줄의 영역

오른쪽 아래 개인화 카드:

- 제목: “오현님을 위한 확인 포인트”
- 문구: “안정형 투자 성향이라면 커뮤니티 기대보다 공식 공시와 실적을 먼저 확인해보세요.”

화면 맨 아래:

- 데이터 출처 영역
- 마지막 갱신 시각 영역
- 문구: “본 서비스는 투자 추천이 아닌 정보 제공을 목적으로 합니다.”

이미지 안의 한국어 문구는 위에서 지정한 문구만 사용해줘. 한국어를 정확하게 표현하기 어렵다면 이상한 글자를 만들지 말고 해당 글자 영역을 비워줘.
