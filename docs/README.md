# 문서 안내

이 폴더에서 개발·제출 기준으로 사용하는 문서는 아래와 같다.

| 문서 | 목적 |
|---|---|
| `FINAL_ARCHITECTURE.md` | 전체 연결 구조와 서비스 책임 |
| `DEVELOPMENT_PLAN.md` | 개발 순서와 완료 기준 |
| `RUNTIME_FOLDERS.md` | 실행 대상과 컴퓨터별 배치 |
| `FRONTEND_FLOW.md` | 비회원·회원 화면 흐름 |
| `DEPLOYMENT_AND_PRESENTATION.md` | 로컬 분산 실행과 발표 준비 |
| `DECISIONS_2026-09-02.md` | 회의에서 확정한 결정 목록 |
| `agent-architecture.md` | 에이전트 아키텍처 설계서(제출 산출물 1) |
| `agent-test-report.md` | 에이전트 시험 결과 보고서(제출 산출물 2) |
| `agent-test-result-report_narrative-source.md` | Backend 서술 채택 분기 시험 |

화면 구현이 끝나 초기 시안 이미지(검색·프로필·요약·상세)는 `archive/design-drafts/`로 옮겼다. 현재 화면 기준은 `FRONTEND_FLOW.md`와 `frontend/tests/shots/`의 실제 스크린샷이다.

`archive/initial-design/`과 `archive/image-prompts/`는 구조 확정 전 작성한 아이디어, 이전 화면 흐름과 생성 프롬프트다. 현재 구현은 아카이브가 아니라 위 최종 문서와 각 서비스의 `GUIDE.md`, `shared/contracts/`를 따른다.
