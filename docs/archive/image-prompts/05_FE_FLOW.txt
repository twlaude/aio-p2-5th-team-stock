16:9 비율, 1920×1080 해상도의 UX 플로우 다이어그램 이미지를 만들어줘.

서비스 이름은 “살래? 말래?”이며, 사용자가 국내 주식 종목을 검색한 뒤 시장 반응과 확인된 근거를 살펴보는 서비스야.

이번에는 개별 완성 화면이 아니라 팀원들이 Frontend의 화면 이동과 개발 범위를 이해하기 위한 전체 화면 흐름을 한 장에 표현해줘.

디자인 조건:

- 밝은 아이보리 배경
- 짙은 네이비 텍스트
- 코랄 레드와 차분한 블루 강조색
- 특정 증권사나 기존 서비스의 디자인을 복제하지 않은 독창적인 구성
- 화면 축소판은 모두 데스크톱 웹 비율
- 스마트폰 목업 사용 금지
- 네 개의 화면 축소판을 왼쪽에서 오른쪽으로 배치
- 화면 사이에 굵고 명확한 화살표 표시
- 복잡한 설명보다 화면 구조와 이동 관계가 잘 보이도록 표현
- 팀 회의에 사용할 고품질 와이어프레임 스타일
- 화면 오른쪽 위에 작은 “DEMO” 배지 표시

첫 번째 화면 축소판:

- 라벨: “FE1 · 종목 검색”
- 서비스명 “살래? 말래?”
- 종목 검색창
- 최근 인기 검색어

두 번째 화면 축소판:

- 라벨: “FE0 · 투자 성향 설정”
- 투자 성향 질문 카드
- “분석 시작하기” 버튼

세 번째 화면 축소판:

- 라벨: “FE2 · 종목 분석 요약”
- 종목 한 줄 평
- 시장 관심 온도
- 근거 확인 정도
- 커뮤니티·뉴스·공시 요약 카드
- 개인 확인 포인트

네 번째 화면 축소판:

- 라벨: “FE2 Detail · 상세 근거”
- 커뮤니티 반응
- 최신 뉴스
- 기업보고서·공시
- AI 종합 설명

화면 사이의 화살표에 다음 설명을 넣어줘.

- FE1에서 검색
- 투자 성향이 없으면 FE0
- 투자 성향 입력 완료
- FE2 분석 결과
- “왜 이렇게 판단했나요?” 클릭
- FE2 상세 근거

FE1에서 이미 투자 성향이 있는 사용자가 FE0을 건너뛰고 FE2로 이동하는 점선 화살표도 표현해줘.

화면 하단에는 다음 흐름을 한 줄로 표시해줘.

“종목 검색 → 투자 성향 확인 → 공통 분석 → 개인 확인 포인트 → 상세 근거”

이미지 안의 한국어 문구는 위에서 지정한 문구만 사용해줘. 한국어를 정확하게 표현하기 어렵다면 이상한 글자를 만들지 말고 해당 글자 영역을 비워줘.
