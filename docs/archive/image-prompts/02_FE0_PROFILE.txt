16:9 비율, 1920×1080 해상도의 한국어 데스크톱 웹 UI 시안을 만들어줘.

서비스 이름은 “살래? 말래?”이며, 사용자가 궁금한 국내 주식 종목을 검색하면 시장 반응과 확인된 근거를 쉽게 설명하는 서비스야.

이번에는 Mock 투자 성향 설정 화면 한 장만 만들어줘. 로그인 ID나 비밀번호 입력 화면은 만들지 마.

이 요청에 이전에 만든 “살래? 말래?” 메인 화면 이미지가 첨부되어 있다면, 그 이미지의 헤더, 색상, 카드 모양, 마스코트 스타일을 동일하게 유지해줘. 참고 이미지가 없더라도 아래 디자인 조건으로 완성해줘.

디자인 조건:

- 스마트폰 화면이 아닌 정면 데스크톱 웹 화면
- 한국의 현대적인 핀테크 서비스처럼 깔끔하고 친근한 분위기
- 특정 증권사나 기존 서비스의 로고·캐릭터를 복제하지 않은 독창적인 디자인
- 밝은 아이보리 배경
- 짙은 네이비 텍스트
- 코랄 레드와 차분한 블루를 강조색으로 사용
- 둥근 선택 카드와 부드러운 그림자
- 초보자와 중장년층도 이해할 수 있는 큰 글자
- 친근하고 둥근 형태의 오리지널 AI 마스코트 캐릭터
- 화면 오른쪽 위에 작은 “DEMO” 배지 표시
- 딱딱한 설문지가 아니라 선택 카드를 누르는 재미가 있는 화면

화면 왼쪽 약 35% 영역:

- AI 마스코트
- 큰 문구: “투자 성향을 알려주세요”
- 보조 문구: “같은 정보도 중요하게 볼 부분은 사람마다 달라요.”
- 진행 상태: “1 / 4”

화면 오른쪽 약 65% 영역:

다음 네 질문을 둥근 카드 형태로 세로 배치해줘.

첫 번째 질문:

“주식 투자를 얼마나 경험했나요?”

- “처음 시작해요”
- “1~3년 경험했어요”
- “3년 이상 경험했어요”

두 번째 질문:

“보유 종목이 단기간에 10% 하락하면 어떻게 느끼나요?”

- “불안해서 정리하고 싶어요”
- “이유를 확인한 뒤 결정하고 싶어요”
- “장기 관점에서 추가 기회를 살펴봐요”

세 번째 질문:

“주로 어느 정도 기간을 생각하나요?”

- “3개월 이내”
- “3개월~1년”
- “1년 이상”

네 번째 질문:

“종목을 판단할 때 무엇을 중요하게 보나요?”

- “가격과 시장 반응”
- “뉴스와 최근 이슈”
- “재무제표와 기업 성장성”
- “안정성과 위험 요소”

화면 오른쪽 아래:

- 강조 버튼: “분석 시작하기”
- 작은 안내 문구: “프로토타입에서는 입력한 정보가 임시로만 사용됩니다.”

이미지 안의 한국어 문구는 위에서 지정한 문구만 사용해줘. 한국어를 정확하게 표현하기 어렵다면 이상한 글자를 만들지 말고 해당 글자 영역을 비워줘.
