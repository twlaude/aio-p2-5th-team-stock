16:9 비율, 1920×1080 해상도의 한국어 데스크톱 웹 UI 시안을 만들어줘.

서비스 이름은 “살래? 말래?”이며, 사용자가 궁금한 국내 주식 종목을 검색하면 시장 반응과 확인된 근거를 쉽게 설명하는 서비스야.

이번에는 첫 번째 메인 검색 화면만 만들어줘. 다른 화면이나 여러 페이지는 만들지 마.

디자인 조건:

- 스마트폰 화면이 아닌 정면 데스크톱 웹 화면
- 한국의 현대적인 핀테크 서비스처럼 깔끔하고 친근한 분위기
- 특정 증권사나 기존 서비스의 로고·캐릭터를 복제하지 않은 독창적인 디자인
- 밝은 아이보리 배경
- 짙은 네이비 텍스트
- 코랄 레드와 차분한 블루를 강조색으로 사용
- 둥근 카드와 검색창
- 부드러운 그림자와 넉넉한 여백
- 초보자와 중장년층도 이해할 수 있는 큰 글자
- 친근하고 둥근 형태의 오리지널 AI 마스코트 캐릭터
- 과도하게 전문적인 주식 차트는 사용하지 않기
- 화면 오른쪽 위에 작은 “DEMO” 배지 표시

화면 상단:

- 왼쪽에 서비스명 “살래? 말래?”
- 오른쪽에 “투자 성향 설정” 버튼과 사용자 아이콘

화면 중앙:

- AI 마스코트
- 큰 제목: “요즘 어떤 종목이 궁금하세요?”
- 보조 문구: “가격 뒤에 있는 뉴스, 공시, 시장 반응을 함께 살펴봐요.”
- 크고 둥근 종목 검색창
- 검색창 안내 문구: “기업명 또는 종목코드를 입력해 주세요”
- 검색 버튼: “살펴보기”

화면 아래:

- 제목: “최근 많이 찾아본 종목”
- 인기 검색어를 카드 또는 칩 형태로 표시
- “1 삼성전자”
- “2 SK하이닉스”
- “3 현대차”
- “4 NAVER”
- “5 카카오”
- 작은 문구: “최근 15분 기준”

매수나 매도를 추천하는 화면처럼 보이지 않게 하고, 시장 정보를 쉽고 재미있게 확인하는 서비스처럼 만들어줘.

이미지 안의 한국어 문구는 위에서 지정한 문구만 사용해줘. 한국어를 정확하게 표현하기 어렵다면 이상한 글자를 만들지 말고 해당 글자 영역을 비워줘.
