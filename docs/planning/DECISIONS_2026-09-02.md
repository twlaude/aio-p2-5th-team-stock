# 2026-09-02 확정 사항

이 문서는 회의 전산문의 모든 발언을 옮긴 회의록이 아니라 개발에 적용하기로 결정한 내용만 정리한다.

1. 지원 대상은 2026-09-01 Snapshot의 KOSPI 시가총액 상위 20개 보통주 기업이다.
2. 가격·뉴스·기업보고서·커뮤니티를 네 개의 독립 MCP 서버로 둔다.
3. MCP Client는 네 서버의 관리자·연결 통로이며 원본 API를 직접 호출하지 않는다.
4. 표준 분석에서는 네 MCP의 기본 결과를 모두 수집한다.
5. MCP Client의 단일 Agent가 결과를 종합해 공통 한 줄 설명과 시장 온도를 만든다.
6. Backend가 로그인, Mock 사용자, 투자 성향, Memory와 개인화를 담당한다.
7. 비회원은 기업명·가격·등락·공통 한 줄 설명까지 확인한다.
8. 상세 근거와 개인화는 회원에게 제공한다.
9. 회원 데이터는 투자 성향이 준비된 Mock 사용자 10명으로 시작한다.
10. 기업보고서는 최신 연간 사업보고서를 저장·임베딩하고 관련 부분만 검색한다.
11. 뉴스·가격·커뮤니티는 실행 시점의 최신 데이터를 조회하며 원본 전체를 중앙 DB에 쌓지 않는다.
12. 관리자 페이지와 실제 주문·추천 기능은 MVP에서 제외한다.
13. MCP 진입점은 각 서버 루트의 `server.py`로 통일한다.
14. Community MCP 구현을 나머지 MCP의 폴더·설정·테스트 기준으로 사용한다.

## 개발 중 다시 결정해야 하는 경우

데이터 제공처의 실제 응답이 계약과 다를 때만 필드 변경을 논의한다. 이미 확정된 서버 분리나 책임을 개인 구현 편의로 변경하지 않는다.
